# Heliys Shop для Telegram

## Запуск на Windows

1. В [@BotFather](https://t.me/BotFather) отзовите токен, который ранее отправили в чат, и получите новый.
2. Распакуйте архив. Для запуска нужен Python 3.10 или новее. Дополнительные библиотеки устанавливать не нужно.
3. Откройте **start.bat** и вставьте новый токен в консоль. Пока вы вводите токен, символы на экране скрыты. Подождите строки с именем бота.
4. Откройте своего бота в Telegram, нажмите «Запустить» и отправьте **/admin** с аккаунта **8717087613**.
5. Создайте и опубликуйте категорию. Затем создайте товар, проверьте карточку в админке и опубликуйте товар.

Бот принимает обновления, пока окно запуска открыто. Для круглосуточной работы запустите один экземпляр **python main.py** на сервере с постоянным диском. На сервере передайте токен через переменную окружения **TELEGRAM_BOT_TOKEN**. Заказы, остатки, пользователи и настройки хранятся в **shop.sqlite3**. Для копирования базы остановите бота, затем сделайте резервную копию файла. Для песочницы Telegram используйте отдельный тестовый токен и **python main.py --test**.

## Товары и оплата

После выбора количества покупатель видит сумму и способ оплаты. Для Stars бот отправляет счёт и получает подтверждение от Telegram.

Для ручной оплаты по СБП бот показывает номер **79161893553**, банк **Т‑Банк** и точную сумму. Покупатель нажимает «Я оплатил» и отправляет фото, изображение или PDF чека. Администратор получает чек и карточку заказа. Перед одобрением сверьте поступление в приложении банка. Отклонение отправляет покупателю причину и кнопку поддержки. Возврат перевода по СБП выполняется вручную через банк.

Рублёвая цена по умолчанию равна цене в Stars, умноженной на **1,32 ₽** за единицу. В карточке товара откройте «Цена по СБП», чтобы задать отдельную цену в рублях. Например, для товара с единицей «1 звезда» установите **1,32**. При количестве 100 итог составит **132 ₽** до бонусов. Выдачу самого товара настройте отдельно.

Официальные правила Telegram требуют оплаты цифровых товаров в Stars. При использовании рублёвого перевода для таких заказов Telegram может ограничить доступ к магазину. [Правила оплаты цифровых товаров](https://core.telegram.org/bots/payments-stars)

Для товара доступны три режима.

- **manual** — бот уведомляет админа после оплаты Stars или получения чека по СБП. Админ нажимает «Одобрить и выдать» и отправляет текст выдачи. При отклонении бот восстанавливает зарезервированный остаток и списанные бонусы. Оплату Stars бот возвращает автоматически.
- **text** — бот отправляет заданный текст за весь заказ после оплаты Stars или одобрения чека админом. Подходит для общей инструкции или постоянной ссылки.
- **invite** — бот создаёт персональное приглашение в приватный канал или группу. Приглашение действует семь дней. Бот подтверждает заявку аккаунта покупателя и отзывает ссылку после входа. Количество в таком заказе равно единице. Добавьте бота администратором с правом приглашать участников и укажите отрицательный числовой ID чата, например **-100…**. Остальные администраторы чата тоже имеют доступ к заявкам на участие.

Каталог при первом запуске пустой. Карточки для Telegram Premium, звёзд и ИИ-услуг можно добавить с ручной выдачей.

### Пример карточки товара

После нажатия «Создать товар» отправьте семь строк. В этом примере **1** — ID существующей категории, **75** — цена в Stars, **10** — остаток.

~~~text
1
Настройка ИИ-сервиса
75
10
manual
Помогу настроить сервис для вашей задачи.
-
~~~

Чтобы добавить фото, откройте карточку товара в админке и отправьте фото по кнопке «Изменить фото». Для приватного доступа укажите **invite** на пятой строке и ID канала на седьмой.

## Бонусы, поддержка и оформление

- Ссылка из профиля закрепляет пригласившего при первом входе. После первой выданной покупки приглашённого бот начисляет **5 ₽ бонусами** на реферальный баланс.
- Промокоды и админские начисления меняют основной бонусный баланс. Бонусы дают скидку по курсу **132 копейки бонусов за 1 ⭐ скидки** или рубль за рубль при оплате по СБП. Минимальный остаток платежа после скидки составляет 1 ⭐ или 1 ₽. «Пополнить баланс» ведёт к пополнению Telegram Stars. Бонусы магазина начисляются внутри бота.
- «Поддержка» и команда **/paysupport** открывают тикеты. Участники могут отправлять текст, фото и документы. Админ может отвечать и закрывать тикеты.
- В разделе пользователей доступны поиск по ID, история посещения, бан, разбан, изменение основного бонусного баланса и отправка сообщений от имени бота. Обязательная подписка настраивается через соответствующий раздел. Бот должен быть администратором каждого указанного канала или чата.
- В меню «Тексты, кнопки и приветствие» нажмите «Текст приветствия» и отправьте новое приветствие обычным сообщением. Для других сообщений нажмите «Тексты бота», выберите раздел и нужный текст. Английская версия выбирается отдельной кнопкой. Реквизиты, сумма, ссылки и другие нужные для покупки данные подставляются автоматически. Фото можно добавить и удалить отдельными кнопками.
- В «Кнопках бота» выберите раздел и кнопку. Затем можно изменить цвет, надпись или эмодзи, посмотреть результат или вернуть исходный вид. Доступны синий, зелёный, красный, цвет темы и фиолетовый значок 🟣. Для эмодзи отправьте сам значок сообщением. Отображение премиум-эмодзи зависит от условий Telegram для владельца бота или дополнительных имён на Fragment.
